# Text encoders

Text encoder model weights are not stored in this Git repository.

Download the following folders from Hugging Face and place them under `text-encoders/McGill-NLP/`:

- https://huggingface.co/McGill-NLP/LLM2Vec-Meta-Llama-3-8B-Instruct-mntp
- https://huggingface.co/McGill-NLP/LLM2Vec-Meta-Llama-3-8B-Instruct-mntp-adapter
- https://huggingface.co/McGill-NLP/LLM2Vec-Meta-Llama-3-8B-Instruct-mntp-supervised

Review and accept the relevant model licenses before downloading.
